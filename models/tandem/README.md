# TANDEM MVS model

`model.pt` is TANDEM's exported 512x320 CVA-MVSNet model. It is loaded by the
project-local asynchronous runtime in `include_voxel/tandem_mvs_runtime.h` and
`src_voxel/tandem_mvs_runtime.cpp`.
